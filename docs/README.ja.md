# 日本語学習

Cognis Study で仮名、漢字、語彙、文を学習できます。

## できること

文字と語彙のつながりや読み全体を調べ、描画や初期デッキで練習し、用意された音声を聞けます。

## 始める前に

日本語パックを有効にして Study で学習言語に登録します。辞書検索と任意の音声生成にはサービス設定が必要で、同梱の内容とは別に扱います。

## はじめに

Study で日本語を選び、Explore のレイヤーを開きます。カードから記載された読みや関連項目をたどり、Flashcards でデッキを練習できます。
