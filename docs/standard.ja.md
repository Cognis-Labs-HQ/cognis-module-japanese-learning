# Cognis Japanese モジュール

Cognis Japanese モジュールは、かな・漢字データ、学習ライブラリ、クラスルームへの入口を含む、インストール可能な日本語学習環境を Cognis Study ゲートウェイに提供します。

## 利用側向けテンプレート

利用側は `study:library` ケイパビリティから、必要な階層だけを指定して `cloneTemplate` を呼び出します。複製されたテンプレートは標準順序と階層関係のメタデータを保ち、省略した階層へのリンクを除き、必須の依存関係を示します。単語や文の作成時には、正規化された文字や空白で区切られた単語からリンクを推定でき、明示的な参照が常に優先されます。

## 使用例

- `/study/hiragana` を開き、ひらがなを学習します。
- 管理者として `/study/library` を開き、モジュールの学習データを確認または追加します。
- `/study/ja-classroom` を開き、Study を通じて日本語クラスルームのセッションを開始します。
- 有効な Cognis アクセストークンで `/api/v1/study/library/entries?scope=global` を呼び出し、グローバルライブラリの項目を読み取ります。
- `study:language:ja` Capability を解決し、モジュール内部をインポートせずに言語記述子を連携します。

## 技術仕様

このモジュールは外部 Cognis 拡張機能です。永続 UUID がリリースをまたいでモジュールを識別し、`requires` エントリが Study ゲートウェイを UUID で宣言します。

### 統合契約

- `bootstrap.js` はプラットフォーム統合に使用する唯一のエントリポイントです。
- 提供される `ctx` は、ルート、UI 登録、Capability、flow hook のための唯一のコンポーネント間バスです。
- ランタイムインポートはリポジトリ相対に限定し、Cognis 内部や他のコンポーネントへ直接アクセスしません。
- スコープ付き登録は、モジュールの無効化またはアンインストール時に削除できます。
- アンインストールフックは要求されたライフサイクルクリーンアップを記録しますが、パッケージ化された学習データセットファイルを直接削除しません。これらのファイルはモジュールパッケージに属し、パッケージとともに削除されます。

### セキュリティ

- ライブラリエンドポイントは、データを読み取る前または変更する前にリクエストを認証します。
- 書き込みには管理者権限が必要で、API 境界でレコードオブジェクトを検証し、レイヤー名を許可リストで制限します。
- API 応答は実装詳細を公開せず、安定した公開エラーを返します。
- 障害は、安全な構造化メタデータとともにホストロガーへ送信されます。

### リリース手順

- `manifest.json`、`package.json`、`package-lock.json` のバージョンを同期し、モジュール UUID は決して変更しません。
- リリースをコミットする前に、`npm install`、`npm test`、`npm run lint`、`npm run manifest:hashes`、`npm run check:manifest`、`git diff --check` を実行します。
- 最後の配布ファイル変更後に `manifest.files` を再生成し、すべてのリポジトリ相対パスと SHA-256 ダイジェストを検証可能な状態に保ちます。
