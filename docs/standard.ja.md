# 日本語コンテンツパック標準

Cognis 日本語モジュールは、ライブラリ内部、データベース、API、ブラウザーコードから分離されたまま、宣言型の日本語学習レコードをホスト所有の Study ライブラリへ導入します。

## 使用方法

Study ゲートウェイとライブラリアダプターを有効にしてから、このモジュールを有効にします。ブートストラップは `ctx` から `study:library` を解決し、`data/library` を取り込みます。管理者と学習者は、モジュール所有のルートではなく、ライブラリアダプターが生成する Study 画面を使用します。

言語記述子は実行可能な子ページを宣言しないため、Cognis Study が `/study/library?language=ja` に生成済みライブラリの移動先を提供します。検証済みの言語クエリは、ライブラリリンク、詳細画面の移動、直接読み込み、ブラウザー履歴で維持されます。認証済み学習者は閲覧でき、作成と公開は引き続きライブラリのスコープ規則で保護されます。

外部モジュールは Study ゲートウェイをコンポーネント依存関係として宣言します。ライブラリアダプターの UUID を単独で導入可能なコンポーネントとして扱わず、必須の `study:library` ケイパビリティを通じて検出します。

## 技術仕様

### パッケージ構成

`data/library/manifest.json` は、パック、不変のパッケージバージョン、コンテンツリビジョン、スキーマ、コンテンツルート、発行者、ライセンスを識別します。直下の各コンテンツディレクトリは `schema.json` の階層に一致し、JSON ファイルには安定したレコードの配列を格納します。

### スキーマとグラフ

スキーマとマニフェストは同じ `ja` 名前空間を所有し、すべてのレコード ID は `ja:` で始まります。スキーマは、ドイツ語、英語、インドネシア語、日本語のローカライズ済みメタデータを使用して `characters`、`alt-characters`、`definitions`、`words`、`sentences` を定義します。セマンティックロールが中立的な生成画面を導きます。フィールドは型付き値と詳細レンダリングヒントを使用し、階層はアクティビティ互換性と関心領域を公開します。有向関係は、ローカライズ済みメタデータ、対象階層、基数、必須対象、順序、必須の削除動作、任意のリゾルバーロールを宣言します。順序付き参照には一意の非負位置を付け、すべての対象は同じパック内に存在します。

パック内のレコード ID には、移植可能な ASCII 英数字、区切り記号、コロンだけを使用します。日本語の字形は `id` ではなく `label` に格納します。これにより、ライブラリのコンテンツレコード識別子契約に準拠して取り込めます。

### ライフサイクルと所有権

`bootstrap.js` は `ctx` を通じて公開ケイパビリティだけを取得し、ライブラリにパックの取り込みを依頼し、日本語記述子を公開して受領情報を記録します。検証、名前空間 ID、トランザクション、冪等性、永続化、ルート、生成 UI はホストライブラリが所有します。このモジュールは API・ページルートを登録せず、ホストデータベースへアクセスしません。

### 更新とライセンス

スキーマ変更ではスキーマバージョンを上げます。コンテンツ変更ではパックバージョンまたはコンテンツリビジョンを更新します。収録レコードにはパックマニフェストで宣言したライセンスと帰属を適用します。
