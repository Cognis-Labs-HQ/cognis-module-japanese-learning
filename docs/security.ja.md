# セキュリティ

日本語学習モジュールは、ホスト認証、ロールベースの認可、境界検証、安全なエラー報告によってライブラリ画面を保護します。

## 使用例

- ホスト提供の `auth:requireAuth` Capability を介して、すべてのライブラリ要求を認証します。
- ライブラリの変更を受け付ける前に、管理者または所有者ロールを要求します。
- 例外メッセージではなく、安定したクライアントエラーコードを返します。

## 技術仕様

### 認可

すべてのライブラリ読み取りには認証済みユーザーが必要です。ライブラリ変更には管理者または所有者が必要であり、要求の読み取りやストア操作より先に認可を実行します。

### 検証とエラー

要求本文にはサイズ制限があり、API 境界で検証されます。予期しない障害は構造化された機密性のないメタデータとともに記録され、クライアントには内部の例外詳細を含まない安定したエラーコードが返されます。
