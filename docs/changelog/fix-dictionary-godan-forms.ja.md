# 五段動詞の活用を補完

**機能ブランチ:** fix-dictionary-godan-forms

## 通常の動詞の活用を解決

ラ行・ワ行・タ行・ナ行の通常の五段動詞に、プロバイダーが所有する活用規則と正確な辞書分類の対応を追加しました。例えば帰るには、帰ります・帰らない・帰った・帰っての各形が用意されます。あるの特殊活用は分離したままです。有効化時にコンテンツの改訂によりホストのライブラリスキーマを更新します。

## 明示的な活用フラグを使用

日本語の基本カードと辞書結果は明示的な活用フラグを宣言します。集合を表す複数形は任意の汎用セットを使い、私から独立カードなしで私たちを生成します。既存の規則経路に対応する同梱録音と生成する文字パターンを保持します。

## 録音と書字練習を保持

既存の経路付き録音は指定された日本語の声と各構成要素の正確な音声を保持します。網羅性テストは、新規のフラグ付きカードも含め、有効な各基本カードと規則に対応する録音を必須とします。ホストは生成した表記から筆順パターンを解決します。

通常の五段ぐ動詞とサ変動詞の規則で新しい辞書語に対応します。サ変動詞は順序付き接尾辞を使い、勉強する と名詞語幹の 勉強 の両方を、別の基本カードなしで処理します。丁寧形・否定形・過去形・て形・可能形・使役の連鎖について、表記と発音を確認します。

## 文で使う語彙を見つけやすくする

文構造カルーセルは `excludeFromBrowse: false` を明示し、その語彙を「語彙」にも表示します。句読点専用カルーセルは除外したままです。テストでは全文の語彙参照、非表示の発音別名、任意フィルターの対象範囲を確認し、日本語の ノート のような級が未設定の単語も対象にします。
