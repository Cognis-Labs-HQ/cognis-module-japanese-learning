# 任意の JLPT フィルター

**Feature Branch:** feature-replace-library-with-new-implementation

## JLPT レベルを自由に選択

JLPT フィルターは未選択で開始し、任意の動詞の種類フィルターと同様に複数選択を許可します。すべての選択を解除すると、JLPT レベルのないカードも含め、すべての語彙カードが表示されます。

## パックの改訂

スキーマ改訂 87 とモジュール・コンテンツパックのバージョン 2.2.83 により、既存の Study Library 契約を通じて選択方針を更新します。
