# テーマ別の練習

**機能ブランチ:** `feature-expand-themed-practice`

## 文脈に沿った練習

食べ物と飲み物、移動と方向、考えをつなぐ表現、人と好みの4つの初期デッキを追加。既存の23表現と、それらに結び付いた意味、仮名の読み、構成要素を集中的に練習できます。

## より明確なイラスト

「とても」と「しかし」のイラストを差し替えます。強い暑さの場面で程度を表し、晴れの予想に反して実際には雨が降る場面で対比を示します。

## 文脈に沿った使い方

各言語の説明と例で、きれい・ゆっくり・あしの絵が示す語義を区別します。だけどの前に文を加えて、対比の内容を明確にします。

## 旅行の語彙

旅行に役立つ語彙十二語に、確認済みの画像と活用形、構成語を関連付けた例文八つ、各言語対応の練習デッキ二つを追加します。旅行の新しい音声は同梱していません。

## 食事の練習

既存の語彙と構成語の音声をそのまま使い、食事に関する多様な例文六つと練習デッキを追加します。合成した音声は技術的な整合性を確認していますが、聴取による検証は行っていません。

## 毎日の行動

既存の語彙と構成語の音声を使い、時間・場所・同行者・方向を扱う日常の例文六つと練習デッキを追加します。
