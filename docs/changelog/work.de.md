# Changelogs externer Module angleichen

**Feature Branch:** work

## Lokalisiertes Changelog-Layout übernehmen

Änderungen externer Module verwenden nun eine Changelog-Datei pro unterstützter Sprache, einschließlich Branch-Herkunft, Überschriften für Release-Zusammenfassungen, vollständiger Details und eines mit der Cognis-Changelog-Erkennung kompatiblen Commit-Abschnitts.

## KI-Beitragsanweisungen präzisieren

Die Repository-Anleitung dokumentiert nun Benennung, Lokalisierung, Unveränderlichkeit und Anforderungen an die Commit-Herkunft von Changelogs für künftige Beiträge.

## Changelog-Konventionen validieren

Eigenständige Tests prüfen Sprachparität, Feature-Branch-Metadaten und lokalisierte Commit-Überschriften für jede Changelog-Familie des Moduls.
