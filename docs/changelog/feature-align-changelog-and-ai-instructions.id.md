# Menyelaraskan changelog modul eksternal

**Feature Branch:** feature-align-changelog-and-ai-instructions

## Mengadopsi tata letak changelog yang dilokalkan

Perubahan modul eksternal kini menggunakan satu berkas changelog untuk setiap bahasa yang didukung, dengan asal cabang, judul ringkasan rilis, detail lengkap, dan bagian commit yang kompatibel dengan penemuan changelog Cognis.

## Memperjelas instruksi kontribusi AI

Panduan repositori kini mendokumentasikan penamaan, pelokalan, sifat tetap, dan ketentuan asal commit changelog untuk kontribusi mendatang.

## Memvalidasi konvensi changelog

Pengujian mandiri memeriksa kesetaraan bahasa, metadata cabang fitur, dan judul commit yang dilokalkan untuk setiap keluarga changelog modul.
