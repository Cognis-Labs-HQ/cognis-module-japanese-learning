# ElevenLabs の発音

**機能ブランチ:** feature-replace-library-with-new-implementation

## すべての録音を再生成

パッケージ内の 3273 件の録音を、この言語に設定された ElevenLabs の声で再生成しました。既存の読み、カード識別子、開始前の無音、間を設けた文の音声合成を維持します。生成ツールは環境変数の認証情報、再開可能な API 応答キャッシュ、ファイルの原子的な置き換えを使用し、パッケージに認証情報を含めません。一覧、帰属表示、コンテンツ改訂、整合性ハッシュも新しい録音に合わせて更新します。
