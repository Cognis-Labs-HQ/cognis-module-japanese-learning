# ガイド付きチュートリアル

この言語紹介は Study の概要の補足として ? から選択します。言語選択、活動への移動、利用できるモジュールの三つの異なる対象を説明し、ページを移動しません。Explore と Flashcards の説明は現在のホスト画面に属します。

## 使用例

Study の概要で言語ナビゲーションから学習教材を選び、活動ナビゲーションから Explore や Flashcards を見つけます。この補足ガイドはページ間を移動せずに操作を説明します。各活動ではその画面に合ったガイドを提供します。

## 技術仕様

ホスト共通の待ち行列でフローティング操作を提供します。初回は次へ・完了のみで中止やスキップはなく、再実行では最後の表示ステップより前にスキップを使えます。最初の表示ステップの後から再開始できます。内容の更新後も完了を維持します。明示的な highlightNext は説明ステップの呼吸するようなアニメーションだけを有効にし、動きを減らす設定では停止します。各段階は表示順に沿って異なる実操作を強調します。ガイドは現在の画面に結び付き、空や省略可能な状態を扱い、移動や所有者解除で後処理を行います。
