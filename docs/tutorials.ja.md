# チュートリアル

Study の概要ガイドはナビゲーションと共通機能を説明します。この言語ガイドでは実際の教材を操作します。レイヤー、フィルター、同じお気に入りとカード、詳細、利用可能な音声、描画練習、カード作成を案内します。

## 使い方

Study 設定で学習言語に登録してください。Explore に初めてアクセスすると開始し、概要の ? から言語ガイドを選んでも開始できます。明示的な選択でその言語の教材を開きます。Explore からの開始では現在のレイヤーを維持します。完了後の再実行は ? のみです。

強調されたカードを開いて詳細を確認し、描画が使える場合は書き取りとツールを試せます。「次へ」は未選択の分岐を飛ばします。作成分岐では種類選択と編集画面を開き、必要なら作成可能なレイヤーへ移動します。カードは自動送信されません。戻る、再開始、完了時には通常の変更破棄確認を維持して画面を閉じます。

## 技術仕様

モジュールはスコープ付き ctx と所有する四言語カタログを使い、固定 ID `introduction` を `study:libraryTutorials` バージョン 1 に登録します。対象、操作、画面寿命は Library が所有し、モジュールは言語固有の説明を提供します。明示的な学習登録が必要で、対応する言語ページでは汎用 Library Explore を置き換え、重複再生を防ぎます。削除時は登録を解放し、代替ガイドを復元します。
