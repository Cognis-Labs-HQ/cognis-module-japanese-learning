# アーキテクチャ

日本語学習モジュールは、Cognis 外部モジュール契約を通じて、日本語の学習コンテンツと個別にマウントできる Study ページを提供します。

## 使用例

- `study:language:ja` を解決して、変更不可能な日本語言語記述子を読み取ります。
- `study:language:ja:library` を解決して、同梱された日本語学習データセットを照会します。
- ホストの SPA ルーターを介して `/study/hiragana`、`/study/library`、または `/study/ja-classroom` をマウントします。

## 技術仕様

### ライフサイクルと統合

`bootstrap.js` はモジュールのライフサイクルエントリーポイントです。認証済みの API と UI、変更不可能な言語記述子、読み取り専用ライブラリ Capability を登録し、プラットフォームの bootstrap flow に記述子を提供します。bootstrap の `ctx` がコンポーネント間統合に使用できる唯一のバスです。

### データ所有権

API は境界検証を担当し、日本語コンテンツの読み込み、グラフ検証、照会、永続化を `api/store.js` に委譲します。同梱のソースデータセットは `data/` にあります。

### ブラウザー画面

3 つのブラウザーエントリーポイントは、`ui/components/` にある個別にマウント可能な Study ページです。ホスト提供のページ契約を使用し、ホストの静的ディレクトリおよび SPA ルートレジストリのみを通じて公開されます。
