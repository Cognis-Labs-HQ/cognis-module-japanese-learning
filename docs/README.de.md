# Japanischlernen

Lernen Sie japanische Kana, Kanji, Wörter und Sätze in Cognis Study.

## Möglichkeiten

Erkunden Sie verknüpfte Schrift und Wörter, vollständige Lesungen, Schreibübungen und Startdecks sowie verfügbare Aufnahmen.

## Vor dem Start

Aktivieren Sie das japanische Sprachpaket und wählen Sie es in Study. Wörterbuchabfragen und optionale erzeugte Sprache benötigen eingerichtete Dienste; gebündelte Inhalte sind davon getrennt.

## Erste Schritte

Wählen Sie Japanisch in Study und eine Explore-Schicht. Öffnen Sie eine Karte für ihre Lesungen und verknüpften Einträge oder üben Sie ein Deck in Flashcards.
