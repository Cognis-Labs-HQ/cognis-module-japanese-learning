# Study Library Host Follow-Up

- Cognis PR #226 updates a previously registered content-pack schema with an `UPDATE` structured command that supplies `values`, while the DB command contract reads `set`. PostgreSQL therefore reaches `Object.entries(command.set)` with `undefined` and reports `Cannot convert undefined or null to object`. Change the schema update in `src/adapters/study/library/store.ts` to use `set: { schema_json: JSON.stringify(schema) }`, and add a PostgreSQL-dialect regression test for upgrading an owned schema at the same schema version. This pack advances its schema revision to avoid that broken update path until the host fix ships.
- Cognis PR #226 validates `study:library:provider` from the public system ctx, but the external-module ctx resolver still reads only the injected route context. Inject the public provider into the module ctx (as `auth:registerProvider` is injected for SSO), then remove the temporary `study:library` carrier branch in `bootstrap.js`; both branches currently use the identical generic provider interface.
- The oversized staged-card delete hitbox is owned by the Cognis Study Library composer, not this external language module. In Cognis PR #226, `src/adapters/study/library/ui/app/pronunciation-editor.js` correctly gates removal on `[data-library-remove-selected-reference]`, but the shared `.btn-cancel` styling can stretch that nested button across the composition input. Constrain `.library-composition-block > .btn-cancel` in `src/adapters/study/library/ui/library-admin.css` with `flex: 0 0 auto` and explicit `inline-size`/`block-size`, then add a browser interaction test proving clicks elsewhere on `[data-library-selected-reference]` neither open the removal confirmation nor remove the staged card. This repository cannot safely override adapter-owned CSS because its UI assets are not loaded into the host Library composer.
- Cognis PR #226 currently derives every non-atomic entry pronunciation recursively with `derivedPronunciation`, but its atomic-writing-unit base case returns the Kana entry's `pronunciation` field (Hepburn romanization) instead of its label. This turns authored higher-layer readings such as `いぬ` into `inu` even though romanization belongs only on the Kana card. Change the base case in `src/adapters/study/library/ui/app/composer-contract.js` to return `entry.label` for atomic writing units, while retaining the direct `pronunciation` value for the Kana layer's own display and editing behavior; add composer-contract coverage proving Kana stays romanized on its card while Vocabulary and sentence derivation concatenate Kana labels.
- Cognis PR #226 still checks a referenced entry's direct `pronunciation` before checking whether its layer is `atomicWritingUnit` in `src/adapters/study/library/ui/app/composer-contract.js`. Consequently, composer-derived Vocabulary and sentence values concatenate Kana romanizations (`ha`, `inu`, `ga`, `suki`) into otherwise Japanese readings even though this pack stores complete Japanese pronunciations. Move the atomic-layer base case before the direct-field return, so recursive derivation returns `entry.label` for Kana while the Kana card itself continues displaying its authored Hepburn field. In the popup regression, render a long segmented sentence such as `私は犬が好き` and assert the complete `わたしはいぬがすき` text remains visible; the composite title grid must wrap or size its grouped reading span instead of clipping the final segment.
- Cognis PR #226 Drawing Practice now uses an aspect-preserving viewport, and this pack supplies explicit `columns` and per-character `groups`. In `src/adapters/study/library/ui/app/drawing.js`, preserve an authored compound pattern's `groups` instead of replacing them with `[own.strokes.length]`; otherwise next-stroke testing treats a multi-character writing unit as one undifferentiated piece. Also replace the hard-coded `0.025` composition inset with bounds-aware spacing so vocabulary characters remain optically adjacent without overlapping. Add browser coverage for a compound Kana and `ゆっくり` at hidden-guide difficulty.
